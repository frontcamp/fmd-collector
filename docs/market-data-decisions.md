
Исходные рыночные данные: требования и решения
==============================================


Предпосылки
-----------

Вначале проекта я столкнулся с тем, что рыночные данные оказалось не так просто найти. Это чуть не поставило исполнение всего проекта под угрозу. Но, подумав, я понял, что для обучения модели и проведения тестов актуальные или даже свежие данные не обязательны. Более того, не обязательно зациклироваться именно на немецкой бирже. Позже, когда проект покажет положительные результаты на исторических рыночных данных, можно будет оформить подписку на актуальные данные и получить доступ к трейдинговому API.


Назначение документа
--------------------

Зафиксировать изученные материалы касательно источников рыночных данных и принятых решений по поводу исследовательской стратегии и будущего перехода к получению актуальных данных и размещению тестовых и реальных ордеров на бирже.


Краткое резюме текущих решений
------------------------------

На этапе исследований следует использовать любые рыночные данные (любых бирж за любой период) в масштабах: 1-5-10-15 секунд и длиной от месяца и более.
Желательно искать данные с курсами одних и тех же активов за разные годы, чтобы можно было сравнивать.
Желательно искать сырые рыночные данные, чтобы преобразовывать их в свечи нужных масштабов самостоятельно.


Торговый брокер
---------------

Не обязательно чтобы данные поступали с того же брокера через которого осуществляется размещение ордеров.
Главное, чтобы исходный поток данных был актуальным и без задержки.

Если выбирать из брокеров, работающих правильно с германской налоговой и исключить необиржи (фантрейдинг) и исключить неудобные инструменты, остаются три: flatex, comdirect, Consorsbank.


Предмет торговли
----------------

в масштабе 1–15 секунд серьёзные игроки обычно работают с самыми ликвидными рынками:

| Что                                       | Почему                                               |
| ----------------------------------------- | ---------------------------------------------------- |
| Фьючерсы на индексы: S&P 500, Nasdaq, DAX | Большой поток сделок, узкие спреды, легко Long/Short |
| EUR/USD и другие главные FX-пары          | Огромная ликвидность                                 |
| BTC и ETH                                 | Круглосуточно, высокая волатильность                 |
| Ликвидные акции США                       | Apple, Nvidia, Microsoft и т.п.                      |
| Нефть, золото, облигации — через фьючерсы | Ликвидно, но больше внешних факторов                 |





Справка
-------

Приблизительное количество информационных пакетов за торговый день, в зависимости от масштаба:

| Масштаб | Пакетов за торговую сессию |
| ------: | -------------------------: |
|     1 s |                     82 800 |
|     5 s |                     16 560 |
|    10 s |                      8 280 |
|    15 s |                      5 520 |
|    30 s |                      2 760 |

Если пакет — это одна завершённая свеча за 1/5/10/15 секунд, минимально он содержит:

| Поле                     | Смысл                                                      |
| ------------------------ | ---------------------------------------------------------- |
| `symbol`                 | конкретный контракт, например `CLZ26`, а не просто «нефть» |
| `time_start`, `time_end` | границы интервала и часовой пояс                           |
| `open`                   | цена первой сделки                                         |
| `high`, `low`            | максимум и минимум сделок                                  |
| `close`                  | цена последней сделки                                      |
| `volume`                 | суммарный объём сделок                                     |
| `trade_count`            | число сделок — если источник даёт                          |
| `is_final`               | свеча закрыта и больше не изменится                        |
