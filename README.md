
Financial Market Data Collector
===============================

FMD Collector — инструмент для автоматизированного сбора исторических данных финансовых рынков и их сохранения в локальной базе данных. Проект также содержит скрипт экспорта, который выбирает из базы указанные активы и данные нужного масштаба за заданный период, а затем сохраняет их в файлы, пригодные для дальнейшей обработки другими инструментами программного комплекса.
