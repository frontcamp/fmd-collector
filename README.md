Назначение проекта
------------------

FMD Converter - компонент программного научно-исследовательского комплекса FMD (далее - FMD-система), предназначенного для исследования и прогнозирования динамики рыночных цен на внутридневных временных масштабах от 1 до 60 секунд.
FMD-системе необходимы биржевые данные, приведённые к единому внутреннему FMD-формату. На этапах разработки и исследования используются преимущественно исторические данные; для практических испытаний система также должна обрабатывать поток актуальных данных, поступающих через API биржи в реальном времени.
FMD Converter получает исходные биржевые данные из разных источников (архивных файлов, REST/потоковых API и др.), выполняет их разбор, валидацию и нормализацию, при необходимости агрегирует их в свечи заданных интервалов (1-60 секунд) и сохраняет результат во внутреннем FMD-формате для дальнейшей обработки компонентами FMD-системы.







Контур: сбор исторических финансовых данных

    Получение, парсинг и сохранение финданных в локальной БД используя адаптеры к онлайн-архивам.

Контур: продолжительный сбор актуальных биржевых данных

    Получение, парсинг и сохранение текущих финданных в локальной БД используя адаптер с биржевым API. Скрипт не останавливается, а продолжает ожидать биржевые данные и по мере их появления сохраняет их в БД.

Контур: экспорт исторических данных в файл

    Экспорт финданных для указанного актива в заданном временном интервале и масштабе в файл в fmd-формате.

Контур: продолжительный экспорт исторических данных в файл

    То же самое, что и обычный экспорт, но без остановки. Скрипт экспорта ждет появления в БД новых данных и по мере появления экспортирует их в конец указанного файла.
