
Financial Market Data Collector
===============================

FMD Collector — инструмент сбора финансовых данных из онлайн-архивов и биржи в локальную БД с возможностью последующего экспорта в fmd-формате.

Контур: сбор исторических финансовых данных

    Получение, парсинг и сохранение финданных в локальной БД используя адаптеры к онлайн-архивам.

Контур: продолжительный сбор актуальных биржевых данных

    Получение, парсинг и сохранение текущих финданных в локальной БД используя адаптер с биржевым API. Скрипт не останавливается, а продолжает ожидать биржевые данные и по мере их появления сохраняет их в БД.

Контур: экспорт исторических данных в файл

    Экспорт финданных для указанного актива в заданном временном интервале и масштабе в файл в fmd-формате.

Контур: продолжительный экспорт исторических данных в файл

    То же самое, что и обычный экспорт, но без остановки. Скрипт экспорта ждет появления в БД новых данных и по мере появления экспортирует их в конец указанного файла.
